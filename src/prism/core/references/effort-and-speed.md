# Effort and speed

Use the smallest amount of work needed to make the current design decision well.

## Default operating mode

- Start with the supplied evidence and the central user difficulty.
- Produce the recommendation before expanding into artifacts.
- Do not treat process depth, source count, state count, or artifact size as signs of quality.
- Load only the references needed for the current decision.
- Stop when additional work is unlikely to change the recommendation.
- Keep successful internal checks invisible. Explain only blockers, material assumptions, and meaningful trade-offs.

## Research limit

- Skip competitive research by default when the problem is directly observable and established UX principles support the direction.
- Do not use healthcare, trust, category familiarity, or the presence of competitors as sufficient reasons to research.
- Research only when the user asks or a specific unknown could materially change the solution.
- When necessary, use one focused search pass and no more than three relevant primary sources.
- Extract only the patterns that affect the current decision, then stop.
- Do not repeat searches merely to increase confidence.

## Wireframe limit

- Build the minimum critical path first.
- Default to one primary screen and no more than four essential alternate, error, or recovery states.
- Do not model every business-rule variation in the first artifact.
- Do not create a design-notes board unless the user requests it.
- Do not build a large custom interactive application when a smaller wireframe communicates the solution.
- Add secondary states only when essential for comprehension or explicitly requested.
- Attempt rendered visual verification once. If the required tool is unavailable, complete other available checks, state the limitation briefly, and stop.

## Expand only with intent

Go deeper only when the user requests depth, the decision has high consequences, or an unresolved issue genuinely blocks a responsible recommendation. State why the additional effort is necessary before doing it.
