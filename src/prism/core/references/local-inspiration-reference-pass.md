# Local inspiration reference pass

Use the bundled library to expand Prism's pattern vocabulary without letting visual references choose the product solution.

Run a bounded pass before an approved wireframe. Run a second, targeted pass during Visual Language Improvement when the constructed screen contains a weak, generic, overly textual, cluttered, or visually unresolved element.

## Retrieve by intent, not filename

Read `../../visual-research/index.md`. Translate the design question into:

- the user job;
- the information shape;
- the current state or transition; and
- the element whose treatment is unresolved.

Choose one or two relevant clusters. Open `../../visual-research/visual-research.html` to visually scan the filtered results. Use the gallery for discovery only: open up to five individual images from `../../visual-research/screenshots/` for accurate inspection, then retain no more than three. Use `../../visual-research/catalog.json` to recover the source title and Pinterest link for any selected ID.

Do not inspect all 300 images during a task. Do not select references from titles alone. If the library has no credible analogue, record “no local fit” and use product reasoning or Mobbin instead.

## Decode selected references

For each retained screen, capture:

- **Observed pattern:** hierarchy, grouping, density, action placement, imagery, and visible state.
- **Why it helps:** the comprehension, comparison, confidence, browsing, or action problem it solves.
- **Evidence class:** interaction, presentation, or mood-only.
- **Adaptation:** how Dopamine components and tokens could express the structural lesson.
- **Boundary:** what cannot be inferred or copied.

## Direction-setting use

Use the selected evidence to challenge the default layout and strengthen the two or three structural directions. References may suggest a credible collection, comparison, progressive question, result, progress, proof, or feedback pattern. They must not introduce a feature or alternate path unsupported by the Product Thinking Gate.

## Visual-polish use

After construction, inventory every meaningful screen element as required by the Visual Language Improvement Pass. Search the local library for elements whose current treatment is generic or whose information shape has a materially better analogue. A reference can justify changing a text block into a comparison, proof block, progressive disclosure, visual collection, persistent state update, or another structure only when the content and user job support it.

Do not add cards, carousels, illustrations, gradients, charts, or decorative surfaces solely because a reference uses them.

## Compact insight packet

Keep only this working note:

```markdown
## Local inspiration insight

**Question searched:** ...
**Selected references:**
- ref-000 — [Pinterest source](...): observed pattern and evidence class

**Structural lessons:**
- ...

**Dopamine adaptation:**
- ...

**Adopt / adapt / reject:**
- ...

**Evidence limits:**
- ...
```

References calibrate judgment; they do not become permanent design-system rules.
